# Nihon

A responsive landing page for a Japanese language school, built with HTML, CSS, and JavaScript.

**[Open the live demo](https://benallal-malek.github.io/nihon-landing/)**

<img src="assets/images/hero.webp" alt="Nihon landing page hero illustration" width="720">

## Features

- Responsive layout for desktop and mobile.
- Mobile menu with keyboard dismissal.
- Navigation highlights the current section as you scroll.
- Demo signup form that validates entries and simulates submission in the browser.

## Run locally

Open `index.html` in a browser or serve the repository root with a local static server.

```sh
python -m http.server 8000
```

Open [localhost:8000](http://localhost:8000/) in your browser.

## Deploy

In the repository’s **Settings → Pages**, select **Deploy from a branch**, choose the `main` branch and `/(root)`, then save.
